# 포함된 로컬 스킬의 라이선스

`.agents/skills/`는 제3자 스킬의 복사본이다. 스킬별 출처와 고정 커밋은 [skills-lock.json](../../skills-lock.json)에 기록했다. 공개 저장소에 포함하면서 원본 라이선스 고지를 함께 보존한다.

| 출처 | 적용 스킬 | 원본 라이선스 |
| --- | --- | --- |
| [obra/superpowers](https://github.com/obra/superpowers) | brainstorming, writing-plans, test-driven-development, systematic-debugging, verification-before-completion | [MIT](obra-superpowers-LICENSE.txt) |
| [mattpocock/skills](https://github.com/mattpocock/skills) | research, prototype | [MIT](mattpocock-skills-LICENSE.txt) |
| [emilkowalski/skills](https://github.com/emilkowalski/skills) | emil-design-eng | [MIT](emilkowalski-skills-LICENSE.txt) |
| [anthropics/knowledge-work-plugins](https://github.com/anthropics/knowledge-work-plugins) | accessibility-review | [Apache-2.0](anthropics-knowledge-work-plugins-LICENSE.txt) |
| [anthropics/skills](https://github.com/anthropics/skills) | frontend-design | [스킬에 포함된 Apache-2.0 고지](../../.agents/skills/frontend-design/LICENSE.txt) |

라이선스 본문은 `skills-lock.json`에 기록된 원본 커밋의 `LICENSE`에서 가져왔다. 이 프로젝트 자체의 모든 문서·시안에 위 라이선스를 적용한다는 뜻은 아니다.
