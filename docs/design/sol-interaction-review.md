# 최소 동작 시안 독립 검수

검수일: 2026-10-01 · 대상: [A/B 제안서](sol-interaction-proposal.md), 기준: [레트로 UX 종합](../research/retro-ux-synthesis.md). 코드·이미지·실기 시험 없이 문서의 논리와 사용자 제약만 확인했다.

**판정: 다음 최소 조작 시안의 비교 설계로 적합. 제품 기본값으로 승인하거나 사용성이 입증된 것은 아니다.**

| 기준 | 검수 결과 |
| --- | --- |
| 기종 정체성 | 첫 행 10열의 3행 QWERTY, 사전 전용 키, 중앙 필기판, 방향·결정 및 돌아가기/페이지 키를 A/B 양쪽에 남겼다. 원형 각인·기능은 설명서와 대조 대상으로 명시했다. 큰 6버튼 대체가 없다. |
| A의 실질적 동작 | 같은 기기의 작업면에 접근해 부분 철자를 입력하고, 실제 사전 표제어 후보를 방향·결정으로 고른 뒤 같은 LCD에서 뜻을 읽고 돌아온다. 입력 중 자판 위치를 고정한다. 10열 가로 폭이 해결됐다는 주장은 하지 않는다. |
| B의 실질적 동작 | CASIO의 필기판을 확대하는 일을 **앱의 새 동작**으로 구분했다. 필기 인식 후보와 사전 표제어 후보를 별개로 확정하며, 확대 중 방향·결정키 노출을 명시했다. 다른 기종에 필기판을 추가하지 않는다. |
| 검증 가능성 | 언어별 짧은/긴 단어와 모르는 한자, 오입력·후보 오선택·시간·반복 피로·한 손·글자 확대·VoiceOver를 평가한다. C의 작은 키 확대 선택은 별도 보조 실험이다. |

**시제품에서 먼저 확인할 위험:** B의 큰 필기면과 원래 위치의 우측 방향·결정키가 좁은 iPhone 세로 화면에 동시에 들어가는지는 아직 알 수 없다. 두 영역을 억지로 축소하면 B의 장점이 사라진다. A는 원래 키가 한눈에 보여도 터치 폭이 부족할 수 있으므로, 후보 선택으로 타건 수가 줄어드는 이득과 오입력 비용을 함께 측정해야 한다. 한글 자모 조합과 일본어 가나·한자 변환 과정은 인식 후보/사전 후보와 혼동 없이 실제 사용자 과제로 검증한다.

수정 요청한 3개 항목(10열 3행 및 원형 대조, B의 후보 확정 경로, 한 손·접근성·반복 피로 평가)은 작성 담당이 반영했고 재확인했다. 추가 문서 수정 없이 비교 시안 검증 단계로 넘길 수 있다.
