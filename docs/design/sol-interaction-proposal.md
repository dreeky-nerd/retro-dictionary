# CASIO 원형 조작을 유지하는 최소 동작 시안 2개

2026-10-01 · 토론용 설계 가설. 사용자 승인안이나 iOS 구현 명세가 아니다. [사례 조사·토론 종합](../research/retro-ux-synthesis.md)의 A(작업면 집중)와 B(필기 패널 확대)를 한 기기에서 비교한다. 첫 기기는 CASIO XD-SW6400이며, 실제 한국어·일본어·영어 사전 데이터를 연결한 뒤 조작을 평가한다. 예시 뜻풀이만으로는 검색 경험을 판단할 수 없다.

**공통 전제:** 닫힌 기기를 열면 화면 위 LCD, 아래 첫 행이 10열인 3행 QWERTY·사전 전용 키·좌측 페이지/돌아가기·우측 방향/결정·중앙 필기 패널이 보인다. 두 안 모두 이 키의 모양, 각인, 상대적 배열을 현대식 6버튼으로 바꾸지 않는다. 실제 키 각인·기능·배열은 CASIO 설명서와 대조할 대상이다. 주변 장식은 줄일 수 있지만 키를 임의로 재배치하거나 입력 중 움직이지 않는다. LCD 세로 확대와 본체 일부 화면 밖 이동은 아직 시험할 변경이다. 손에 닿는 키 폭이 충분해졌다고 가정하지 않는다.

## 시안 A — 원래 자판에 가까이 다가가 검색

| 장면 | 보이는 것과 동작 |
| --- | --- |
| 열기 | 접힌 CASIO가 열리고, 잠깐 기기 전체를 확인한다. 검색을 시작하면 같은 기기의 자판과 LCD가 정면으로 가까워진다. 베젤·경첩 일부는 화면 밖으로 갈 수 있지만 원래 키의 행과 위치는 남는다. |
| 입력·후보 | 원형 키를 탭하면 키 눌림과 LCD의 검색어가 함께 반응한다. 첫 타건 뒤 키의 위치·크기는 고정한다. 원형 사전 키로 검색 언어/사전을 고른다. 부분 철자에 맞는 후보는 실제 사전 표제어에서만 보여준다. |
| 선택·읽기·뒤로 | 방향·결정으로 후보를 열고, 같은 LCD에 뜻풀이를 읽기 좋은 크기로 표시한다. 돌아가기·페이지 키로 목록과 본문을 오간다. iOS 키보드는 명시적으로 선택하는 보조 입력이며 원형 키를 통한 검색 흐름을 없애지 않는다. |

**언어별 후보:** 영어는 입력한 철자와 일치하는 표제어 후보를 보여준다. 한글은 자모 입력·음절 조합 방식이 아직 정해지지 않았으므로, 조합 중 표시와 완성 음절 기준 후보를 구분해 시험한다. 일본어는 가나로 읽기를 입력하는 경우와 읽는 법을 모르는 한자를 찾는 경우를 분리한다. 전자에서는 읽기와 표제어 후보를 혼동하지 않게 표시하고, 후자는 이 시안의 문자 키만으로 해결됐다고 보지 않는다. 후보는 빈도를 추측해 뜻을 생성하지 않고 실제 사전 항목으로 이동한다. 몇 글자만으로 모든 검색이 끝난다는 약속도 하지 않는다.

**실험 기준:** 각 언어 사용자가 짧고 긴 검색어, 비슷한 철자, 후보 선택, 긴 뜻풀이를 수행한다. 기존 축소 시안과 검색 완료 시간·오입력 및 수정 횟수·후보 오선택·뜻 읽기·기기 동일성 평가를 비교한다. 한 손 조작, 글자 확대·VoiceOver에서 흐름이 끊기는지, 10분 반복 후 피로도도 본다. 가로 피치가 거의 늘지 않았다면 반복 오입력이 그대로일 수 있다. 이 경우 작업면 집중만으로 키 문제를 해결했다는 주장은 폐기한다.

## 시안 B — 원래 필기 패널을 펼쳐 검색

| 장면 | 보이는 것과 동작 |
| --- | --- |
| 열기·전환 | A와 같은 열린 CASIO에서 하단 중앙의 원래 필기 패널을 누른다. 패널의 테두리·질감이 이어지는 확대 입력면이 열리고, 작은 패널은 그 진입점으로 남는다. 패널 확대는 앱에 더한 동작이며 실물 기능의 정확한 복각으로 부르지 않는다. |
| 쓰기·인식 확인 | 손가락으로 글자를 쓰면 확대 패널 안에 **필기 인식 후보**가 뜬다. 방향 키로 후보를 반전 선택하고 결정 키로 확정한다. 틀리면 패널의 지우기로 획을 지우거나 다시 쓴다. 확대 중에도 원래 우측 방향·결정 키를 같은 위치에 보이게 하는 안이며, 공간이 충분한지는 시험한다. |
| 사전 후보·읽기·뒤로 | 확정한 글자/검색어가 원래 LCD에 들어간 뒤 **사전 표제어 후보**가 뜬다. 방향·결정으로 뜻을 열고 돌아가기로 후보에 복귀한다. 확대 패널은 이때 원래 크기로 접히며, 원형 자판으로 언제든 전환할 수 있다. SHARP RD-9100MP·iriver D26에는 없는 필기 부품을 같은 기능인 것처럼 덧붙이지 않는다. |

**언어별 과제:** 영어는 짧은 단어를 손으로 쓰는 비용을 타이핑과 비교한다. 한글은 음절·자모 인식 결과와 수정 횟수를 본다. 일본어는 가나뿐 아니라 읽는 법을 모르는 한자를 찾는 과제를 별도로 둔다. 필기 인식 엔진의 정확도와 세 언어 지원은 **검증되지 않았다**. 인식 후보와 사전 표제어 후보는 서로 다른 단계로 표시해야 한다.

**실험 기준:** 같은 언어의 동등한 난도 과제를 A/B에 나눠 수행한다. 입력 완료 시간, 인식 오류·다시 쓰기·후보 오선택, 뜻풀이까지 도달한 비율, 한 손 조작·글자 확대·VoiceOver 가능 여부, 10분 반복 후 피로와 선호, 원래 기기를 조작하는 느낌을 본다. B가 인식 수정 때문에 더 느린 언어·과제에서는 기본 입력 방식으로 채택하지 않고 보조 경로로만 검토한다.

**선택 보조 C:** A에서 작은 키를 오래 누를 때 주변 키를 손가락 바깥에 확대해 보여주고 손을 떼어 확정하는 방법은 별도 조건으로만 시험한다. 매 타건에 강제하지 않는다. A와 B의 실패를 감추는 장치로 계산하지 않는다.
