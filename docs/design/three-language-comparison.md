# 같은 CASIO 외형의 세 언어 기본 사전 시안

2026-10-01 · [전체 버튼 현지화 수정 시안](09-localized-all-buttons.png)은 **사용자 언어에 따른 기본 화면과 버튼 표기**를 보여주는 정적 시안이다. [이전 비교 이미지](08-three-language-comparison.png)는 한국어·영어 열의 기능키에 일본어 각인이 남은 오류가 있어 수정 전 기록으로만 둔다. 세 기기의 은색 본체, 원형 3행 QWERTY, 사전 단축키, 중앙 필기 패널, 좌측 페이지/뒤로와 우측 방향/결정키의 형태·배열은 동일하다. 나라별 실물 CASIO 기종을 복제한 것이 아니라 **한 앱의 현지화된 가상 키 표기**다.

내장 image_gen으로 [A 자판 시안](06-sol-a-keyboard-search.png), [B 필기 시안](07-sol-b-handwriting.png), [CASIO 키 도면](references/casio-keys.png), [실물 사진](references/casio-sw6400-bcn.jpg)을 참조해 **한 장** 생성했다. 생성 지시의 핵심은 “같은 iPhone·같은 CASIO 본체를 큰 세 열로 반복하고, LCD만 `국어사전/사과`, `国語辞典/りんご`, `English Dictionary/apple`의 단일어 뜻풀이로 바꾼다. 한/영·かな/英数·ABC 입력 상태와 선택적 한국어/영어 추가 풀이를 기본 정의와 분리해 작게 표시한다. 원형 QWERTY·필기판·방향/결정키를 유지하고 일반 키보드나 6버튼으로 대체하지 않는다.”였다. 한 차례 교정에서 한국어 열 문자 키에만 작은 한글 보조 글자를 추가하고 LCD 표기를 `한글 입력`으로 고쳤다.

뜻풀이 문장은 **이미지용 예시**이며 계약된 사전 원문이 아니다. 한국어 키의 작은 한글 문자는 **앱 입력 레이어 제안**이다. 그림이 작아 각 자모의 두벌식 대응 정확성·가독성을 검증할 수 없으며 원래 기기의 실제 각인이라고 해석하면 안 된다. 한글 조합, 일본어 로마자 변환·필기 인식, 각 언어 사전 데이터, iPhone의 작은 키 터치 정확도도 검증하지 않았다. 원형 키의 세부 각인·기능은 출시용 도면에서 설명서와 다시 대조해야 한다.

## 09 수정 내용과 생성 지시

08의 일본어 기능키 잔상을 고치기 위해 imagegen으로 09를 만들었다. 원형의 상단 **7개 사전 키**와 하단의 전환/삭제, 작은 기능키, 필기판 수정/인식, 페이지/뒤로, 방향/결정 위치는 유지하고, 표시 언어를 열마다 바꿨다. 상단 7키 예시는 한국어 `전체·국어·영한·한영·일한·단어장·메뉴`, 일본어 `総合·国語·英和·和英·日韓·単語帳·メニュー`, 영어 `All·English·EN-KO·KO-EN·JA-EN·Words·Menu`다. 영어 문자 키에는 A–Z·숫자만, 일본어 키에는 로마자·가나, 한국어 키에는 로마자·두벌식 보조 글자를 표시한다.

최종 교정 지시는 “KO/EN 물리 키의 일본어를 모두 없애고 각 언어의 짧은 기능 명칭으로 바꾸되 원형 키 수·모양·배열은 유지한다. KO·EN 상단 7키에서 빠진 `일한`·`KO-EN`을 복원한다. 한국어 보조 글자는 QWERTYUIOP=`ㅂㅈㄷㄱㅅㅛㅕㅑㅐㅔ`, ASDFGHJKL=`ㅁㄴㅇㄹㅎㅗㅓㅏㅣ`, ZXCVBNM=`ㅋㅌㅊㅍㅠㅜㅡ`의 키별 대응을 참고한다. LCD의 세 단일어 사전 뜻풀이와 외형은 그대로 둔다.”였다. 이미지 모델이 만든 작은 각인은 **제작용 키 매핑 도면이 아니다**. 실제 입력 구현 시 이 대응을 별도 도면과 기기 화면에서 검증한다.
