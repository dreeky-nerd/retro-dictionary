# 세 언어 비교 시안 시각 검수

검수일: 2026-10-01 · 대상: [세 언어 최종 이미지](08-three-language-comparison.png). 초안과 교정본을 원본 크기로 직접 열어 비교했다. 교정본은 최종 파일명으로 저장됐다.

**판정: 교정본 v2를 정적 비교 시안으로 채택.** 같은 CASIO XD-SW6400 형태와 원형 QWERTY·사전 단축키·중앙 필기 패널·방향/결정키가 세 열에 일관되게 남아 있다. LCD의 `국어사전/사과`, `国語辞典/りんご`, `English Dictionary/apple`은 각 언어의 짧은 단일어 뜻풀이와 일치한다. 기본 풀이와 선택적 한국어·영어 추가 풀이 표시가 구분되며, LCD·키보드가 잘리지 않는다. 이전 B 시안의 잘못된 `영한사전` 라벨은 이 이미지에 없다.

초안은 한국어 열에 `한글 보조각인`이라고 적었지만 키캡에 실제 한글이 없었다. v2에서는 한국어 열에만 작은 한글 보조 문자가 표시되고 상태 문구도 `한글 입력`으로 바뀌어 차이가 더 명확하다. 일본어 열은 로마자/필기, 영어 열은 ABC 상태를 표시한다.

**한계:** 작은 한글 자모의 정확한 두벌식 대응과 실제 iPhone 크기에서의 판독성은 이 생성 이미지로 확인할 수 없다. 세 사전 뜻풀이는 시안용 예문이며 계약된 사전 원문이 아니다. 한글 조합, 일본어 입력, 필기 인식, 키 터치 성공률도 검증되지 않았다. 정확한 원형 키 각인 도면이나 구현 완료 화면으로 사용하지 않는다.
