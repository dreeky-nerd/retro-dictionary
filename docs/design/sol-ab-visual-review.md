# A/B 정적 시안 시각 검수

검수일: 2026-10-01 · 기준: [최소 동작 제안](sol-interaction-proposal.md), [CASIO 키 자료](references/casio-keys.png). [A 이미지](06-sol-a-keyboard-search.png)와 [B 이미지](07-sol-b-handwriting.png)를 원본 크기로 열어 확인했다.

**판정: 두 이미지를 비교용 정적 시안으로 사용할 수 있다.** A는 원형 자판을 누르고 검색어 `app`에서 예시 표제어 후보를 방향·결정키로 고르는 장면과, 같은 LCD의 뜻 화면을 오른쪽에 연결했다. 상단 10키·중단 9키·하단 Shift/삭제의 3행 구조, 사전 단축키, 중앙 필기 패널, 왼쪽 페이지/돌아가기, 오른쪽 방향·독립 결정키가 식별된다.

B는 같은 기기의 중앙 필기 패널을 크게 펼쳐 자판 일부를 일시 가린다. **오른쪽 방향·결정키와 왼쪽 페이지·돌아가기 키는 가리지 않는다.** 확대면의 `余/予`는 필기 인식 후보, LCD의 `余白/余暇`는 사전 표제어 후보로 다른 단계임을 라벨과 번호가 구분한다. 패널 확대를 앱에서 추가한 동작이라고 명시한다. 초안에 남았던 A의 ‘자판 검색’ 표시는 최종 이미지에서 ‘B·필기 검색’으로 교정됐다.

**한계:** B에서 펼친 패널과 원위치 방향키가 시각적으로 공존한다는 것만 확인했다. 실제 iPhone에서 두 영역이 손가락으로 누르기 충분한지, 한 손 사용·큰 글자·VoiceOver·반복 입력이 가능한지는 검증되지 않았다. A도 10열의 가로 터치 폭이 커졌다는 증거가 아니다. 키 각인·일부 세부 비율과 화면 글자는 생성 이미지의 근사치이므로 설명서 기준의 정확한 복제 도면이나 실제 사전 데이터의 증거로 사용하지 않는다.

주 에이전트 최종 확인: B 이미지의 LCD와 뜻풀이 인셋에 남은 ‘영한사전’ 표기는 일본어 예시와 맞지 않는다. ‘일한사전’으로 보정해야 하는 문구 오류다. 현재 결과는 비교용 정적 시안이며 실제 터치와 필기 인식은 검증 전이다.
