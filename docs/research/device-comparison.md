# 일본·한국 전자사전 재현 후보 비교

조사일: 2026-09-30. 사용자 승인 범위는 일본 CASIO EX-word, 한국 SHARP 리얼딕·iriver 딕플 계열의 비교 분석이다. 개별 기종의 최종 선정, 상세 설계, 코드 구현 승인을 의미하지 않는다.

## 판단 요약

**첫 동작 검증 대상은 CASIO XD-SW6400, 한국 흑백 기기 후보는 SHARP RD-9100MP, 한국 컬러 기기 후보는 iriver D26을 추천한다. D100은 멀티미디어 재현 범위가 넓어 후속 후보로 둔다.**

이는 향수·인지도에 대한 사용자 조사 결과가 아니라, 사용자 요구와 공개 자료의 충실도를 기준으로 한 제작 순서 제안이다. 한국 사용자에게 어떤 모델이 더 친숙한지는 아직 검증하지 않았다. 네 모델 모두 역대 누적 판매 1위라고 주장할 근거는 없다.

| 후보 | 제품에서 확인되는 특징 | 프로젝트 적합성 판단 | 원형 재현의 주요 과제 |
|---|---|---|---|
| CASIO EX-word XD-SW6400 | 도트 LCD, 키보드와 별도 필기 패널, 사전·학습·계산기, 공식 설명서 공개 | 조작 동작과 판정 기준을 구체적으로 정하기 좋은 첫 기준 | 필기 인식, 출판사별 사전·음성·학습 자료, 외부 저장매체 기능 |
| SHARP 리얼딕 RD-9100MP | 흑백 화면, 덮개 바깥 MP3용 OLED·버튼, 사전·MP3·FM·녹음·전자책 | 한국형 흑백 전자사전 외형 후보. 닫힌 상태도 의미 있는 경험 | 전체 메뉴 설명서 확보, FM 수신·과거 음악 서비스·음성 엔진 |
| iriver 딕플 D26 | 컬러 화면, 물리 자판, 통합검색과 학습·음악 기능 | 컬러 기기로 확장할 때의 우선 후보 | 정확한 메뉴·단축키·저장 동작 자료와 수록 콘텐츠 확보 |
| iriver 딕플 D100 4GB | 2009년 다나와 경유 판매 1위, 동영상·인강 등 복합 기능 | 멀티미디어 전자사전의 별도 확장 후보 | 영상·학습 콘텐츠·과거 파일 형식 및 연동 서비스의 범위 |

기종별 세부 근거: [CASIO 분석](casio-sw6400-analysis.md), [한국 기기 분석](korean-device-analysis.md). 제조사 발표는 발표 시점의 사양 근거이며, 실물 조작이나 현재 사용 가능성을 확인한 결과가 아니다.

자료 확보 수준은 다르다. CASIO는 공식 전체 설명서를 확보해 대표 동작을 확인했다. 한국 세 기종은 공식 설명서를 확보하지 못했고, RD-9100MP·D26은 제조사 보도자료, D100은 당시 판매 집계와 보도에 근거한다. 특히 D100의 기술 사양은 제조사 원문 확인 전 잠정 정보다. 샤프 화면 크기는 공식 발표 5인치와 유통 자료 5.4형이 충돌해 확정하지 않았다.

## 판매 근거의 범위

- XD-SW6400: 2007년 5월 BCN 조사 대상 판매점에서 색상을 합산한 기종별 판매 대수 1위(15.8%). 같은 시기 XD-SW4800은 2위(12.9%). 학생 전용 콘셉트를 우선한다면 SW4800도 후속 비교 가치가 있지만, 이번에는 이미 제안한 SW6400을 상세 조사한다. [BCN](https://www.bcnretail.com/news/detail/070621_7730.html)
- D26: 2007년 상반기 다나와의 클릭·저장·판매·가격 등록업체 등 혼합 지표에서 5개월 연속 1위로 소개됐다. 순수 판매 대수 1위로 표현하지 않는다. [다나와](https://dpg.danawa.com/news/view?boardSeq=63&listSeq=1400503&past=Y)
- D100 4GB: 2009년 1월 1일~12월 셋째 주 다나와 경유 판매량 1위. 전국 모든 채널 또는 역대 판매량 순위가 아니다. [다나와](https://dpg.danawa.com/news/view?boardSeq=64&listSeq=1605184&past=Y)
- RD-9100MP: 2010년 초 다나와 판매 분석에서 인기 흑백 기종으로 확인된다. RD-9000MP의 과거 매출 1위 실적을 후속 모델인 RD-9100MP의 실적으로 옮기지 않는다. [다나와](https://dpg.danawa.com/mobile/news/view?boardSeq=63&listSeq=1696122)

## 재현 범위를 결정하는 세 가지 차이

### 화면을 재현하는 것과 콘텐츠를 재현하는 것은 다르다

원래 사전 메뉴, 방향키와 확인 키, 단어장 저장 방식은 동작을 관찰해 재구현할 수 있다. 그러나 원래 출판사의 뜻풀이·음성·문제집을 그대로 제공하는 일에는 데이터와 사용 권한이 필요하다.

예를 들어 원래 메뉴가 특정 출판사 사전 이름을 표시한다면, 그 안에 Wiktionary 결과를 넣고 원래 사전인 것처럼 보여주면 안 된다. 원본을 확보해 제공하거나, 실제 데이터 출처에 맞게 표시하는 방식을 사용자와 결정해야 한다. 후자는 원문까지 동일한 재현이 아니다. 기존 데이터 조사에서 찾은 공개 API는 현대적 사전 공급 후보이며, 구형 기기의 모든 수록 사전을 대체하지 못한다.

기존 판본을 역사 자료로 보존하는 기능은 요청하지 않았으므로 기본 요구로 추가하지 않는다. 기본 방향은 최신 사전 내용이며, 원래 동작과 달라지는 부분을 기록한다. [사전 데이터 조사](korean-data-and-slang.md), [일본어·영어 데이터](japanese-english-data.md)

### 멀티미디어 기기는 사전 외에도 재현할 부분이 많다

RD-9100MP 제조사 발표만 해도 MP3와 검색 동시 사용, 오디오북, 전자책, FM 프리셋·녹음, 보이스 레코더, 외부 OLED 조작이 등장한다. 따라서 흑백 모델을 선택했다고 구현 범위가 자동으로 작아지지 않는다. [샤프 발표](https://www.newswire.co.kr/newsRead.php?no=222665)

앱의 파일 재생·녹음 동작, 원래 기기의 무선 수신·카드 슬롯 같은 하드웨어, 지금도 사용 가능한지 확인해야 할 과거 서비스는 각각 따로 평가해야 한다. 인터넷 방송 재생을 FM 튜너와 동일한 기능으로 세거나 가짜 채널로 동작 완료 처리하지 않는다. 하드웨어 의존 기능의 동일 재현은 현재 보장할 수 없다.

### 스킨을 바꿔도 개인 데이터는 보존되어야 한다

외형뿐 아니라 기종별 메뉴·키·디스플레이가 바뀌는 요구다. 추천 구조는 공통 사전 데이터·업데이트·개인 단어장과 기종별 표현·조작을 구분하는 것이다. 첫 모델부터 범용 에뮬레이터를 만들자는 뜻은 아니다.

스킨 변경 때 최근 검색과 저장 단어를 보존하는 방향을 제안한다. 원형 단어장의 개수 제한이나 저장 형식이 다르면 원래 화면에서 보이는 범위와 앱이 보존하는 전체 데이터를 어떻게 연결할지 명시해야 한다. 기기 외형 변경을 이유로 사용자 단어를 삭제하지 않는다.

## iPhone에서 풀어야 할 가장 큰 문제: 자판 크기

기기 전체를 줄이면 물리 자판이 터치 자판이 되면서 손가락으로 누르기 어려워진다. 예를 들어 가로 390pt 화면에 10개 키를 한 줄로 넣으면 여백을 빼기 전에도 키 간격은 평균 39pt다. 이는 설명용 계산이며 특정 iPhone이나 후보 모델의 실제 측정값은 아니다. Apple의 일반 버튼 권장 터치 영역은 44×44pt다. 작은 키마다 보이지 않는 터치 영역만 무작정 늘리면 이웃 키와 겹친다. [Apple 버튼 지침](https://developer.apple.com/design/human-interface-guidelines/buttons)

권장안은 다음 세 경험을 같은 상태로 연결하는 것이다.

| 경험 | 용도 | 유지해야 할 것 |
|---|---|---|
| 기기 전체 보기 | 열고 닫기, 외형 감상, 전용 키로 조작 | 선택 기종의 비율·키 배열·원래 메뉴 |
| 자판/뜻풀이 확대 | 원형 자판을 정확히 누르거나 긴 설명 읽기 | 검색어·커서·선택 행·이전 위치 |
| 휴대폰 입력 보조 | 한글 조합, 일본어 변환, 긴 검색어·붙여넣기 | 같은 검색 요청과 같은 결과, 기존 자판 사용 가능 |

모든 기기를 같은 색과 버튼으로 통일하지 않는다. CASIO의 필기 패널, 샤프의 외부 OLED, 아이리버의 컬러 화면을 각 기기의 특징으로 남긴다. 가로 화면 전환은 비교할 후보이며, 실제 시안 없이 최종 해법이라고 단정하지 않는다.

## 현실감을 만드는 데 필요한 자료

| 대상 | 확보해야 할 근거 | 피해야 할 임의 재현 |
|---|---|---|
| 몸체·힌지 | 정면·측면·닫힌 모습, 치수, 개폐 영상 | 사진 한 장으로 두께·축 위치 확정 |
| 키 | 배열, 각인, 누름·복귀 모습, 연타·길게 누르기 동작 | 모든 키에 같은 소리·기능 배정 |
| LCD | 실제 글자 크기·해상도·반전·명암·화면 전환 | LCD에 CRT 주사선·글리치 추가 |
| 소리 | 기종별 실제 입력 확인음·버튼·개폐 녹음 | 다른 기종 음원을 원본이라고 표시 |
| 메뉴 | 설명서 및 실제 입력과 결과의 대조 | 메뉴가 열리기만 하면 구현 완료 처리 |

문서만으로 물리적 키감과 개폐음·LCD 응답 시간을 확인할 수는 없다. 지금은 실물 녹음·정밀 치수·모든 상태 영상이 확보되지 않았다. 원본 자료의 사용 조건도 별도로 기록해야 한다. [Apple 콘텐츠 사용 지침](https://developer.apple.com/app-store/review/guidelines/#intellectual-property)

Higgsfield는 기종 선정 후 재질·조명·모션 비교 영상을 요청할 때 활용한다. 모델의 진짜 음원이나 정확한 키 각인을 생성 결과로 대체하지 않는다. 런타임에 사용자가 조작할 본체를 제작할 때는 편집 가능한 레이어 또는 분리된 3D 부품이 필요하며, 생성 영상만으로 이를 확보했다고 판단하지 않는다. 아직 생성 작업은 수행하지 않았다.

## 개선할 사용성 — 기능 추가와 구분

옛 기기의 모든 불편을 단정하지 않고 다음 검증 항목을 제안한다. 구형 기기에도 통합검색·이력·화면 복원이 있으므로 이를 최신 앱에서 처음 만든 기능처럼 설명하지 않는다.

흥미로운 원형 기능은 D26의 **사용자 추가사전**이다. 제조사는 신조어나 다른 뜻을 직접 등록할 수 있다고 설명했다. D26 재현 시 개인이 기록한 뜻과 운영자가 검수해 배포하는 최신 사전 항목을 구분하면 원래 기능과 지속 갱신 요구를 함께 살릴 수 있다. 개인 메모를 검증된 정의로 승격하거나 자동으로 전체 사용자에게 공개하지 않는다. [레인콤 발표](https://www.newswire.co.kr/newsRead.php?no=216092)

- 검색 실패 시 철자·읽기 후보를 제시하되 사용자가 입력한 단어를 조용히 다른 단어로 바꾸지 않는다.
- 최근 검색·단어장은 원래 기능과 같은 결과를 제공하면서, 확대 화면·입력 보조에서도 유지한다.
- 신조어는 원래 사전 항목과 구분되는 출처·사용 맥락·검수일을 제공한다.
- 업데이트 중에도 검색을 막지 않고, 적용 실패 시 마지막 정상 데이터를 유지한다. 온라인 전용 사전은 통신이 없을 때의 범위를 명시한다.
- 기기를 여는 모션은 새로 시작하는 경험에 사용하고, 잠깐 앱을 전환한 뒤 복귀할 때는 직전 검색 상태를 복원한다.

## 다음 검증에서 판정할 것

1. **CASIO 설명서 기준의 동작 대조:** 검색 → 결과 선택 → 뜻 → 점프 → 뒤로, 단어장 저장·재개, 계산기 메모리 연산. 설명서의 기대 동작과 결과가 맞아야 한다.
2. **iPhone 입력·가독성:** 작은 화면에서도 기기 전체 보기에서 원형 자판 확대·입력 보조로 이동하고 한·일·영 검색을 끝낼 수 있어야 한다. 실제 기기 시험 전에는 통과했다고 말하지 않는다.
3. **사전 공급:** 각 사용자 언어에서 실제 뜻풀이·출처가 나오고, 미제공 언어를 자동 번역으로 숨기지 않아야 한다.
4. **데이터 갱신:** 새 판본 적용 전후 개인 단어장 참조가 유지되고, 갱신 실패 후에도 마지막 정상 데이터가 검색되어야 한다.
5. **원형 기능 누락 검사:** 설명서의 전체 기능 목록을 확보해 완료·미구현·자료 부족·콘텐츠 미확보·하드웨어 의존을 구분한다. 첫 동작 검증의 성공은 전체 기능 완성을 의미하지 않는다.

현 단계 결과는 조사와 후보 추천이다. 전체 네이티브 앱의 제작 기간·가격, 원본 콘텐츠 라이선스 비용, 모든 기종의 완전 재현 가능성은 산정하지 않았다.
