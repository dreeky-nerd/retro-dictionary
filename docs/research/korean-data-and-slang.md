# 한국어 사전과 최신 신조어 데이터 조사

확인일: 2026-09-30. 목적: 한국어·일본어·영어가 실제로 검색되는 레트로 사전 앱의 데이터 후보 선정. 공개 문서 조사이며 인증키 발급이나 실제 API 호출 검증은 아직 하지 않았다.

사용자 확정 원칙: 사용자 언어에 맞는 사전을 기본 제공하고, 요청하면 한국어·영어 사전 풀이를 함께 보여준다. 번역기가 아니라 사전이다. 아래의 다국어 데이터는 실제 사전 항목과 풀이를 제공하는 용도로 검토하며, 기계번역으로 빈 언어쌍을 메우는 계획은 없다.

## 결론

한국어는 한국어기초사전을 중심으로 시작하고 표준국어대사전·우리말샘을 보완 공급원으로 검토할 수 있다. 일본어·영어 표제어 검색은 별도의 데이터가 필요하다. 한국어기초사전의 다국어 번역은 한국어 어휘에 붙은 번역이므로, 이것만으로 완전한 영한·일한 사전을 확보했다고 해서는 안 된다.

최신 신조어는 기존 사전의 신규 항목을 활용하되 별도의 검수된 편집 데이터로 보완하는 것을 제안한다. 조사 범위에서는 한·일·영 최신 신조어를 모두 제공하고 자유로운 앱 재배포까지 허용하는 단일 공급원은 확인하지 못했다.

## 한국어 후보

| 공급원 | 제공 방식과 용도 | 확인된 조건·제약 |
|---|---|---|
| [한국어기초사전](https://krdict.korean.go.kr/eng/openApi/openApiInfo) | 검색·상세 API. 한국어 표제어와 뜻풀이에 영어·일본어를 포함한 다국어 번역을 제공 | 인증키 필요. 한국어 학습 어휘 중심. 영어·일본어 전체 어휘를 포괄하는 독립 사전은 아님 |
| [표준국어대사전](https://stdict.korean.go.kr/openapi/openApiInfo.do) | 검색·상세 API. 품사·뜻풀이·원어·발음 등 한국어 설명의 공급원 | 인증키 필요. XML/JSON 제공. 최신 인터넷 유행어 전체 수록을 보장하지 않음 |
| [우리말샘](https://opendict.korean.go.kr/service/openApiInfo) | 검색·상세 API. 올린 날짜·고친 날짜 기준 조회, 새로 올린 순 정렬, 뜻풀이·대역어 검색 가능 | 인증키 필요. 신규 등록일은 유행 시작일이나 신조어 여부와 다름. 전체 결과를 ‘표준어’라고 표시해서는 안 됨 |

[국어사전 통합 API 안내](https://kdict.korean.go.kr/info/openapi)는 사전별 데이터와 이용 정책이 다를 수 있다고 명시한다. 공급원별 키와 정책을 따로 확인한다.

## 비용·이용 조건

- 한국어기초사전은 [공공데이터포털](https://www.data.go.kr/data/15105059/openapi.do)에 무료로 기재되어 있다. 트래픽은 기관 정책에 따른다고 안내하므로, 신청 전 고정 호출량을 단정하지 않는다.
- [한국어기초사전 저작권 정책](https://krdict.korean.go.kr/kor/kboardPolicy/copyRightTermsInfo)은 별도 표시가 없는 자료에 CC BY-SA 2.0 KR을 적용하며 상업 이용을 허용한다. 저작자 표시와 변경 저작물의 동일조건 배포가 필요하다. 발음·이미지·소리 등은 항목별 이용 조건이 다를 수 있다.
- [국어사전 통합 저작권 정책](https://kdict.korean.go.kr/info/copyright)도 CC BY-SA 2.0 KR을 기본으로 명시한다. 특히 출전이 있는 용례는 원저작권자에게 이용 허락을 받아야 한다고 안내한다. 기본 뜻풀이와 인용 예문을 같은 권리로 취급하지 않는다.
- 위 정책을 근거로 앱 전체 코드가 반드시 공개되어야 한다고 단정하지 않는다. 사용 데이터, 편집·번역한 데이터, 앱 코드를 구별하여 표시·배포 조건을 검토한다.
- 장기 캐시·대량 수집·오프라인 배포 방식은 사용할 원자료의 조건과 API 운영 정책을 함께 확인한 뒤 정한다. 현재 문서 조사로 무제한 API 수집을 허가받았다고 보지 않는다.
- 한국어기초사전 공식 API 안내는 XML을 설명하는 반면 공공데이터포털에는 JSON+XML 메타데이터가 보인다. 실제 구현은 제공기관 문서를 우선하고 인증키 발급 뒤 응답을 확인한다.

## 한국 신조어의 출처

| 출처 | 활용할 수 있는 역할 | 자동으로 해서는 안 되는 것 |
|---|---|---|
| 우리말샘의 신규·수정 항목 | 기존에 등재된 표현의 뜻 확인, 갱신 후보 탐지 | ‘새로 등록됨’을 ‘요즘 유행함’으로 간주 |
| 국립국어원 공개 신어 자료집 | 연도별 신어와 언어 변화의 근거 | 오래된 조사 자료를 현재 유행어 목록으로 표시 |
| 캐릿의 요즘어 사전·밈 기사 | 최신 표현과 사용 맥락을 발견하는 참고 자료 또는 계약 후보 | 구독 권한을 앱 내 재배포 권한으로 간주 |
| 실제 사용 사례·사용자 제보 | 아직 사전에 없는 표현 후보 발견 | 제보 하나만으로 확정된 뜻·유래로 공개 |

국립국어원은 공개 가능한 기존 신어 자료집을 연구보고서에서 제공한다고 안내한다. 이는 실시간 신조어 API를 뜻하지 않는다. [공식 답변](https://m.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=322047&searchCondition=&searchKeyword=)

캐릿은 ‘요즘어 사전’과 최신 유행어·밈 콘텐츠, 자문단 검증 방식을 직접 소개한다. [서비스 소개](https://www.careet.net/About), [요즘어 사전](https://www.careet.net/Dictionary). 공개 API 또는 자유로운 앱 재배포 허가는 확인하지 못했다. 사용하려면 [저작권 정책](https://www.careet.net/Policy/Copyright)에 맞는 별도 제휴 조건을 확인해야 한다. 현재 가입·구매·문의는 진행하지 않았다.

## 신조어 편집 방식 — 제안

‘MZ’는 사용자 의도를 나타내는 표현으로 이해하되 실제 콘텐츠에서는 국가·사용 집단·맥락을 구분한다. 세 언어의 비슷해 보이는 밈을 일대일 번역으로 단정하지 않는다.

최소 항목은 다음과 같이 제안한다.

- 표현, 언어, 쓰이는 지역·상황.
- 짧은 뜻풀이, 직접 작성하거나 이용 권한이 확인된 예문.
- 원출처 링크와 최근 확인일.
- 격식 수준, 비속어·비하 표현 여부 등 사용 시 알아야 할 맥락.
- 검수 상태. 근거가 없는 유래는 단정하지 않는다.

운영 순환은 **후보 발견 → 복수의 독립 사용례로 의미 확인 → 풀이·예문 작성 → 검수 → 게시 → 정기 재확인**으로 제안한다. 기사 간 복제는 독립 근거로 세지 않는다. AI는 정리·번역 초안을 도울 수 있지만 단독 사전 출처가 될 수는 없다. 갱신 주기는 아직 정하지 않았으며 자동화도 만들지 않았다.

## 첫 기능 검증의 기준 — 제안

1. 한국어·일본어·영어 입력별 실제 데이터 검색을 확인한다.
2. 기존 사전 결과와 신조어 결과에 출처와 뜻을 표시한다.
3. 동일 철자라도 언어·품사·뜻이 다르면 구별한다.
4. 검색 결과 없음과 공급원 연결 실패를 구별한다.
5. 한국어 풀이가 없는 항목을 있는 것처럼 번역해 숨기지 않는다.
6. 신조어의 최근 확인일과 실제 근거를 표시한다.

일본어·영어 후보의 세부 내용은 [별도 조사](japanese-english-data.md)를 참고한다. 이 문서는 공급원 조사이며 데이터 연동 구현 완료를 의미하지 않는다.
