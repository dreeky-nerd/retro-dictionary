# 레트로 전자사전 외형·조작 리서치

- 조회일: 2026-09-30
- 목적: 학습 효율보다 전자사전의 **물리적 외형과 조작감**을 즐기는 앱의 기준 자료를 모은다.
- 범위: 2000년대 접이식 전자사전 두 기종. 아래의 **확인된 사실**은 제조사 자료에만 근거한다. **앱 제안**은 원기기의 기능을 그대로 재현한다는 뜻이 아니다.

## CASIO XD-H4000: 입력하면 화면이 즉시 반응하는 사전

**확인된 사실**

- 키보드 위쪽에 `広辞苑`(일본어 사전), `英和`(영일), `和英`(일영), 복수 사전 검색 등의 전용 모드 키가 있다. 모드 키를 누르면 해당 사전의 첫 화면으로 이동한다. 일부 키는 보조 키를 먼저 눌렀다 떼고 눌러 두 번째 기능을 연다. [설명서 23–24, 27–28쪽](https://www.casio.com/content/dam/casio/global/support/manuals/exword/pdf/003-ja/comb/XD-H4000_JA.pdf).
- 기본 검색은 글자를 하나씩 입력할 때마다 맞는 후보를 바꾸는 `すぐ出るサーチ`다. 일괄 검색으로 바꿀 수도 있다. 후보에서 반전된 표제어의 뜻 **처음 네 줄**을 화면 아래에 미리 보여준다. [설명서 21쪽](https://www.casio.com/content/dam/casio/global/support/manuals/exword/pdf/003-ja/comb/XD-H4000_JA.pdf).
- 후보는 방향 키로 반전 위치를 옮기고 결정 키로 연다. 뜻 화면에서 위·아래 키는 한 줄씩, 페이지 키는 한 화면씩 넘긴다. `戻る`에 해당하는 키를 누르면 한 단계 전으로 돌아가며, 뜻 화면에서는 해당 단어가 포함된 목록으로 돌아간다. [설명서 29–32쪽](https://www.casio.com/content/dam/casio/global/support/manuals/exword/pdf/003-ja/comb/XD-H4000_JA.pdf).
- 사전을 펼치면 자동으로 켜지고 닫으면 꺼진다. 전원 키로 켜면 이전 화면을 이어 볼 수 있다. 단, 사전 모드 키로 켜면 그 모드의 첫 화면으로 진입한다. [설명서 26쪽](https://www.casio.com/content/dam/casio/global/support/manuals/exword/pdf/003-ja/comb/XD-H4000_JA.pdf).
- 사전별 검색 이력에서 이전에 찾은 단어를 다시 열 수 있다. 전체 이력은 최대 1,000건이며 오래된 항목부터 지운다. [설명서 86쪽](https://www.casio.com/content/dam/casio/global/support/manuals/exword/pdf/003-ja/comb/XD-H4000_JA.pdf). 이 설명서에서 발음 재생 기능은 확인하지 못했다.

**설명서에 있는 실제 조작 예:** `英和` 키 → `fine` 입력 → 입력에 맞춰 나타나는 목록에서 방향/페이지 키로 `fine`을 반전 선택 → 결정 키 → 영일 뜻 화면 → 뒤로 키 → 해당 단어가 있던 후보 목록. 앞부분은 [설명서 61쪽](https://www.casio.com/content/dam/casio/global/support/manuals/exword/pdf/003-ja/comb/XD-H4000_JA.pdf), 마지막 복귀 동작은 [31–32쪽](https://www.casio.com/content/dam/casio/global/support/manuals/exword/pdf/003-ja/comb/XD-H4000_JA.pdf)에 각각 기술되어 있다. 이 문장은 두 설명을 연결한 예시이며, 설명서에 이 순서 전체가 한 문단으로 인쇄된 것은 아니다.

## SII SR-G10000: 고밀도 흑백 화면과 다기능 물리 키

**확인된 사실**

- 키에는 영일·일영·옥스퍼드·COBUILD 등의 사전 바로가기와 `이력`, `돌아가기`, `점프`, `문자 크기`, `표시 스타일`, `결정/번역`이 각각 배치된다. 위·아래 커서 키는 한 줄 이동, 좌·우/페이지 키는 한 페이지 이동을 맡는다. `결정/번역`은 발음 표시가 있는 단어나 문장에서는 발음도 재생한다. [SII 설명서 10–11쪽](https://www.sii.co.jp/cp/download/pdf/SR-G10000.pdf).
- 미리보기 화면의 위치를 **아래/오른쪽**으로 전환하고, 본문에서는 행간·괘선 표시를 바꾸는 전용 표시 스타일 키가 있다. 글자 크기는 다섯 단계로 바꿀 수 있다. [SII 설명서 10–11쪽](https://www.sii.co.jp/cp/download/pdf/SR-G10000.pdf).
- `돌아가기` 키는 직전 화면으로 돌아가며, 입력 중에는 입력 문자를 한꺼번에 지우는 역할도 한다. 표제어 선택 → 번역 전체 화면 → 뒤로 → 목록/미리보기 → 뒤로 → 입력 화면이라는 복귀 구조가 설명서에 그려져 있다. [SII 설명서 10–11, 30–31쪽](https://www.sii.co.jp/cp/download/pdf/SR-G10000.pdf).
- `이력` 키는 이미 검색한 어구를 다시 표시한다. 발음용 스피커·이어폰과 물리적 음량 다이얼은 외형도에 명시된다. [SII 설명서 8–11쪽](https://www.sii.co.jp/cp/download/pdf/SR-G10000.pdf).

**색상·밀도에 관한 주의:** SII 설명서의 `흑백`은 제품 사양이다. 화면을 초록빛, 황색 또는 강한 픽셀 격자로 표현하는 것은 이 제품에 대해 확인된 사실이 아니라 앱을 위한 미술 선택이다. XD-H4000 역시 사양란은 해상도만 적으므로 그 기기의 정확한 LCD 색조를 이 자료로 단정할 수 없다.

## 앱으로 옮길 때의 제안 — 원기기 사양과 구분

| 원기기에서 확인된 요소 | 앱 제안 | 판단 이유·유의점 |
| --- | --- | --- |
| 접이식 외형과 화면/키보드 분리 | 화면 위에 경첩·베젤, 아래에 누를 수 있는 QWERTY 및 전용 키를 배치한다. 화면과 키의 눌림 상태가 분명하게 보이게 한다. | 외형을 보는 재미와 누르는 행위를 중심에 둔다. 실제 제품 로고·키캡 그래픽의 직접 복제는 별도 권리 검토가 필요하다. |
| 글자 입력 즉시 후보 갱신, 선택 항목 반전, 짧은 뜻 미리보기 | `입력 → 촘촘한 후보 목록 → 반전 선택 → 뜻`을 기본 순환으로 삼는다. 키 입력마다 화면이 작게 갱신되게 한다. | 검색 결과를 빨리 얻는 편의보다 버튼을 누르며 화면이 변하는 감각에 맞는다. |
| 한 줄/한 페이지 이동과 명시적 뒤로 키 | 방향 키·페이지 키·결정·뒤로를 화면 버튼과 실제 키보드 양쪽에서 조작하도록 고려한다. | 원기기의 이동 리듬을 살린다. 최종 키 매핑은 타깃 기기(모바일/데스크톱)가 정해진 뒤 결정한다. |
| 흑백 고밀도 LCD와 문자 크기 전환 | 제한된 회색조·선명한 반전 커서·좁은 행간을 기본 시각 언어로 검토한다. 가독성을 위해 화면 해상도를 기계적으로 320×240 또는 640×480에 고정하지 않는다. | 인상은 보존하되 현대 화면에서 읽을 수 있어야 한다. 색조와 픽셀 질감은 제안이다. |
| 이력 키, 일부 기기의 발음 재생 | 최근 검색을 다시 여는 전용 키를 고려하고, 발음은 발음 자료가 있는 항목에만 별도 버튼으로 둔다. | 이력은 기기 공통의 조작 재미다. XD-H4000에 발음 기능이 있었다고 가정하지 않는다. |
| 열고 닫을 때 전원 상태 변화, 이전 화면 복귀 | 시작·종료 시 열림/닫힘을 짧은 전환 연출로 실험한다. | 장시간 전환이나 필수 대기 시간은 원기기 감성과 별개이며 앱에서 강제할 이유가 없다. |

### 설계에서 남은 선택

타깃 기기와 사용 언어가 아직 정해지지 않았다. 따라서 물리 키의 화면상 크기, 한글 입력 방식, 실제 키보드 단축키, 화면 비율은 여기서 확정하지 않는다. 디자인을 먼저 좁힌다면 **XD-H4000의 간결한 후보/미리보기 흐름**과 **SR-G10000의 고밀도 흑백 화면·키 배열**을 각각 작은 시안으로 비교할 만하다. 두 기기의 요소를 섞은 화면은 역사적 한 모델의 정확한 복각이 아니라 앱의 새로운 조합임을 명시해야 한다.
