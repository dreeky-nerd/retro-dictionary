# 한국 전자사전 외형·조작 기준 후보: RD-9100MP, 딕플 D26·D100

조사일: 2026-09-30

## 판단 범위와 결론

목표는 **계산기·학습 메뉴 등 부가 기능까지 원형대로 재현하면서 실제 사전 내용은 계속 갱신하는 앱**이다. 외형만 입히는 것으로 요구를 축소하지 않는다. 기존 사전 데이터·음성·학습 자료의 앱 재배포 권한은 별도로 확보해야 한다. 제조사 보도자료를 기기 사실의 우선 근거로, 다나와의 당시 자체 판매 분석을 시장 맥락의 근거로 사용했다. 세 모델의 **공식 사용설명서는 이번 공개 웹 조사에서 확보하지 못했다.** 따라서 검색어 입력→결과 선택→본문→뒤로, 계산기, 방향키의 정확한 배치·반응과 같은 메뉴 단위 조작은 아직 복각 사양으로 확정할 수 없다.

기본 검색·항목 화면의 조작 흐름을 먼저 검증해야 한다면 공식 설명서가 확보된 [CASIO XD-SW6400 조사](casio-sw6400-analysis.md)를 실험 기준으로 사용할 수 있다. 그 뒤 한국 흑백 기기는 RD-9100MP, 컬러 기기는 D26의 자료를 확보해 각각의 기능과 조작을 재현하는 순서를 추천한다. CASIO 동작에 한국 기기 외형만 씌우는 것은 원형 재현이 아니다.

## 모델별 확인 사항

### 샤프 리얼딕 RD-9100MP

[샤프전자의 2007-01-30 신제품 보도자료](https://www.newswire.co.kr/newsRead.php?no=222665)는 제품 사진의 출처이기도 하다. **RD-9100MP는 RD-9000MP의 후속 모델**이며 사전·회화·문고·검정 콘텐츠 총 67권을 수록했다. 제조사는 저반사 LCD, 사전 검색과 MP3 동시 사용, 오디오북, e-book, FM 프리셋 10개와 방송 녹음, 보이스 레코더, 영어 음성 RealSpeak를 명시했다. **전면부의 별도 OLED 표시장치와 버튼으로 본체를 열지 않고 선곡·재생 정보 확인**이 가능하다는 점이 구별된다.

화면 크기는 제조사 발표와 [2007년 다나와 분석](https://dpg.danawa.com/news/view?boardSeq=63&listSeq=1400503&past=Y)에서 **5인치**, [2010년 다나와 분석](https://dpg.danawa.com/mobile/news/view?boardSeq=63&listSeq=1696122)에서 **5.4형**으로 달라 수치를 확정하지 않는다. 2010년 분석은 이 모델을 명시적으로 *흑백 전자사전*이라고 설명한다. 같은 제조사 발표에 등장하는 **RD-CX3의 컬러 LCD·터치스크린·아이콘 메뉴는 RD-9100MP의 사양이 아니다**. 또한 2007년 다나와 글은 RD-9100MP에 VoxWare를 적었지만 제조사 발표는 RealSpeak를 RD-9100MP, VoxWare를 RD-CX3에 연결하므로 음성 엔진은 제조사 발표를 우선한다. [샤프전자 발표](https://www.newswire.co.kr/newsRead.php?no=222665), [다나와 2007 분석](https://dpg.danawa.com/news/view?boardSeq=63&listSeq=1400503&past=Y), [다나와 2010 분석](https://dpg.danawa.com/mobile/news/view?boardSeq=63&listSeq=1696122)

### 아이리버 딕플 D26

[레인콤의 2007-01-02 판매 시작 발표](https://www.newswire.co.kr/newsRead.php?no=216092)와 거기에 실린 기기 사진을 원자료로 삼을 수 있다. 흰색·검은색, 둥글게 처리한 외장, 노트북식 키패드, 4.3인치 컬러 와이드 LCD와 163.4 × 83.6 × 21.5mm 크기를 제조사가 명시한다. 국립국어원 표준국어대사전, 콜린스·랜덤하우스 영영사전 등을 포함해 한국어·영어·일본어·중국어 52개 콘텐츠를 탑재했다. 단어·문장 발음과 청취 속도 조절을 지원하며, MP3나 라디오를 들으면서 사전 검색·e-book·사진 보기·전자수첩을 사용할 수 있었다. 내부 저장공간은 1.2GB다. [레인콤 발표](https://www.newswire.co.kr/newsRead.php?no=216092)

조작감과 연결되는 원래 기능으로는 **어느 화면에서나 즐겨 쓰는 메뉴로 이동하는 ‘마이 메뉴’**, 사전에 없는 신조어·다른 뜻을 사용자가 직접 등록하는 **‘사용자 추가사전’**, 한글 독음으로 외국어 철자를 찾는 **‘차이코프스키’ 검색**이 확인된다. 당시 펌웨어·콘텐츠 업데이트 가능이라는 발표는 현재도 업데이트 서버가 운영됨을 입증하지 않는다. [레인콤 발표](https://www.newswire.co.kr/newsRead.php?no=216092) 날짜는 *판매 시작*의 근거이고, [다나와 2007 자료](https://dpg.danawa.com/news/view?boardSeq=63&listSeq=1400503&past=Y)의 ‘2006년 12월’ 표기는 상품 등록 시점으로 보이므로 출시일로 혼용하지 않는다. 다나와는 D26이 5개월 연속 1위라고 썼지만 해당 글은 **종합 순위** 맥락이므로 순수 판매량 1위로 바꾸어 말하지 않는다.

### 아이리버 딕플 D100 4GB

[2009-06-30 전자신문의 신제품 보도](https://www.etnews.com/200906300043)는 회사 발표를 인용해 ‘스터디 팔레트 D100’의 둥근 외장·매끈한 마감·페블 스타일 키보드, 흰색·분홍색, 한국어 사전 8종과 영·일·중·불·독 사전, 이미지가 포함된 디지털 브리태니커, PMP 수준 영상·음향을 전한다. 이는 **제조사 원문이 아닌 언론 보도**라는 한계가 있다. [다나와의 2009년 판매 분석](https://dpg.danawa.com/news/view?boardSeq=64&listSeq=1605184&past=Y)은 *다나와를 통한 판매량*에서 D100 4GB가 해당 연도 최다 판매 모델이었다고 직접 집계했고, 4.3인치 화면, 인터넷 강의·동영상·MP3·FM·자필 인식을 언급한다. 전 시장 전체 판매 1위로 확장해서는 안 된다. [2010년 다나와 분석](https://dpg.danawa.com/mobile/news/view?boardSeq=63&listSeq=1696122)은 4.3형 TFT LCD와 480 × 272 해상도, 추가 뷰어·녹음 기능을 열거하지만 이는 당시 매체의 제품 요약이며 실제 화면별 동작 근거는 아니다.

## 앱으로 옮길 때의 경계

* **검증된 사실에서 온 제안:** RD-9100MP의 선명한 흑백 저반사 화면 분위기와 좁은 상태창, D26의 컬러 와이드 화면·노트북식 키패드·‘마이 메뉴’ 단축 이동은 각 기기의 확인된 특징을 참고할 수 있다. D26의 사용자 추가사전 개념은 현대 신조어를 사용자가 저장하는 동작의 영감이 되지만, 원 메뉴 문구·위치·저장 규칙의 정확한 복제는 설명서 확인 후 결정한다. [샤프전자 발표](https://www.newswire.co.kr/newsRead.php?no=222665), [레인콤 발표](https://www.newswire.co.kr/newsRead.php?no=216092)
* **하드웨어 의존:** RD-9100MP의 바깥쪽 OLED·물리 MP3 버튼·클램셸 개폐, D26의 물리 키감·FM 라디오·전지 수명, D100의 자필 입력·동영상/강의·음향은 앱 화면만으로 동일 경험을 보장할 수 없다. 앱에서는 그래픽·키보드 반응·선택적 소리 같은 *해석*으로 범위를 정해야 한다. [샤프전자 발표](https://www.newswire.co.kr/newsRead.php?no=222665), [레인콤 발표](https://www.newswire.co.kr/newsRead.php?no=216092), [다나와 D100 분석](https://dpg.danawa.com/news/view?boardSeq=64&listSeq=1605184&past=Y)
* **미확인:** 세 모델의 공식 사용설명서, 검색 결과의 행 배열·전환 키·뒤로 가기·히스토리의 실제 동작, 계산기 탑재 여부, 현재 펌웨어·사전 데이터 다운로드 경로는 이번 조사에서 확인되지 않았다. 상품 소개·중고 판매 설명을 이런 메뉴 동작의 확정 근거로 쓰지 않는다. 기존 기기 사진과 상표, 수록 사전 본문을 앱에 재사용할 권한도 별도 확인이 필요하다.
