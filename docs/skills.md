# 프로젝트에 포함한 스킬

2026-09-30에 `C:\ai-workspace\.agents\skills`에서 다음 10개 폴더를 실복사했다. 스킬의 보조 문서와 스크립트를 함께 보존했으며 원본은 수정하지 않았다. 출처와 원본 메타데이터는 프로젝트 루트의 `skills-lock.json`에 기록했다.

| 스킬 | 이 프로젝트에서의 용도 | 이번 작업 상태 |
|---|---|---|
| brainstorming | 레트로 감성과 실용 사전 중 핵심 목적 확인, 구현 전 디자인 논의 | 목적 확인에 적용 |
| research | 일본 제조사의 제품·설명서를 Sol 에이전트로 조사 | 적용 |
| frontend-design | 기기 외형, LCD와 키 배열을 중심으로 고유한 화면 제작 | 후속 작업용 준비 |
| emil-design-eng | 키 눌림, 포커스, 화면 전환의 반응 다듬기 | 후속 작업용 준비 |
| prototype | 외형 후보와 조작감을 비교하는 검토용 시제품 | 후속 작업용 준비 |
| accessibility-review | 작은 LCD 글자와 버튼의 가독성, 키보드 입력 점검 | 후속 작업용 준비 |
| writing-plans | 선택된 디자인을 구현 가능한 작업으로 나누기 | 후속 작업용 준비 |
| test-driven-development | 검색·선택·되돌아가기 상태 전이 검증 | 후속 작업용 준비 |
| systematic-debugging | 입력·화면 동작 오류의 원인 파악 | 후속 작업용 준비 |
| verification-before-completion | 파일과 스킬 복사 결과 확인 후 완료 보고 | 적용 |

마케팅, SEO, 이메일, 출시 전략 스킬은 현재 목적에 필요하지 않아 포함하지 않았다. 여러 디자인 시스템 생성 스킬을 중복 설치하지 않고 외형과 상호작용에 직접 필요한 스킬을 선택했다.

프로젝트 폴더를 별도로 여는 새 세션에서도 `.agents/skills/`를 탐색할 수 있는 형태로 배치했다. 현재 대화의 스킬 카탈로그가 실시간으로 재등록되었다는 뜻은 아니다. 별도의 전역 설정이나 MCP 인증 정보는 복사하지 않았다.
