# 레트로 전자사전 앱 — 조사 브리프

작성일: 2026-09-30  
갱신: 2026-10-01. 첫 기준 기종은 CASIO XD-SW6400, 후속 스킨은 SHARP RD-9100MP·iriver D26이다. 사용자 후속 요청에 따라 MP3 같은 불필요한 기능을 제외하는 방향으로 조정했다. 아래 초기 조사 당시의 전체 기능 재현·기종 미선정 표현보다 [최신 상세 시안](design/mockup-spec.md)과 AGENTS.md의 범위를 우선한다. 상세 구현 설계는 아직 미확정이다.

## 핵심 방향

사용자가 원하는 것은 **전자사전의 외형과 조작감을 즐기면서 실제 사전 기능도 사용하는 레트로 앱**이다. 한국어·일본어·영어를 지원하며 최신 신조어·속어까지 찾을 수 있기를 원한다. 성공 기준은 기기를 조작하는 느낌과 출처가 있는 실제 검색 결과를 함께 제공하는 것이다. 예제 데이터만으로 제품 기능을 충족했다고 보지 않는다.

사용자가 추가로 확인한 원칙: **사용자 언어에 맞는 사전을 기본으로 보여주고, 요청하면 한국어·영어 사전 풀이도 제공한다. 근본은 번역기가 아니라 사전이다.** 검색어의 언어, 화면 언어, 사전 풀이 언어를 구별하고 원자료의 뜻·품사·용례와 출처를 유지한다. 추가 사전의 데이터가 없을 때 자동 번역 결과를 사전 풀이인 것처럼 제시하지 않는다.

추가로 확인된 요구는 iOS 네이티브 우선, 이후 Android 네이티브 제작, 지속적인 사전 갱신, 언어별 초기 외형과 스킨 변경, 터치로 여는 동작, 원래 버튼 소리, 디스플레이 질감과 현실적인 애니메이션이다. **특정 기종의 계산기·학습 메뉴 등 부가 기능까지 원형대로 재현**한다. 상세 내용과 제안은 [현대적 레트로 콘셉트](modern-retro-concept.md)에 기록한다.

인터페이스와 외형은 앱으로 구현 가능하다. 다만 실제 고무 키의 탄성이나 힌지의 물리적인 저항까지 화면만으로 동일하게 만들 수는 없다. 시각적인 눌림, 소리, 지원 기기의 진동으로 그 인상을 보완한다. 실제 iPhone에서 검증해야 한다.

## 조사에서 확인할 것

- 현재 일본 제조사가 제공하는 제품 정보와 과거 제품의 공식 자료를 구분한다.
- 판매 페이지가 남아 있다는 이유만으로 현재 사용률이나 시장 성장을 추정하지 않는다.
- 화면의 색과 밀도, 키 배열, 전용 기능 키, 힌지와 화면 비율을 살핀다.
- 설명서에서 입력 → 결과 선택 → 뜻 보기 → 돌아가기의 조작 흐름을 확인한다.
- 제조사의 사실 설명과 앱에 적용하자는 제안을 분리한다.

상세 출처와 모델별 근거는 [일본 대표 제품 조사](research/japanese-models.md), [구형 제품과 조작 조사](research/retro-interaction.md)에 정리한다.

후속 조사에는 [애니·드라마 등장 사례](research/screen-appearances.md), [한국어 사전·신조어 데이터](research/korean-data-and-slang.md), [일본어·영어 데이터](research/japanese-english-data.md)를 추가했다. 작품 등장 빈도와 실제 시장 점유율은 구분한다.

사용자가 일본 CASIO EX-word, 한국 SHARP 리얼딕·iriver 딕플의 비교 분석 방향에 동의했다. [재현 후보 비교](research/device-comparison.md)에서는 XD-SW6400·RD-9100MP·D26·D100의 기능·자료 확보·iPhone 사용성을 비교하고 첫 검증 순서를 제안한다. 분석 동의를 개별 기종의 최종 제작 승인으로 해석하지 않는다.

## 일본 제품의 현재 상태

CASIO는 2025년 3월기 결산 설명회 자료에서 전자사전 시장 축소에 대응해 하드웨어 신규 개발을 중지하고 영업 체제를 축소했다고 명시했다. 이를 전 제품 판매 종료로 해석해서는 안 된다. [공식 결산 자료, 인쇄 13쪽](https://www.casio.co.jp/content/dam/casio/global/corporate/ir/library/results/2025/setumei25_all.pdf)

SHARP Brain PW-S3의 공식 제품 개요에는 조회 시점에 ‘재고 소량’이 표시된다. 제품 정보와 지원 자료의 존속은 확인되지만, 이 자료만으로 일본 전체 사용률이나 판매량을 말할 수는 없다. [공식 제품 개요](https://jp.sharp/edictionary/products/pws3/overview/)

## 외형 방향 비교 — 제안

| 방향 | 인상과 장점 | 고려할 점 |
|---|---|---|
| 흑백 LCD와 실버 몸체 — 우선 추천 | 한눈에 오래된 전자사전으로 인식하기 쉽고 글자·버튼에 집중할 수 있음 | 의도적으로 거친 글꼴을 쓰더라도 한글·일본어 가독성은 유지해야 함 |
| 보조 화면이 있는 전자사전 | 작은 입력창과 기능 키가 기기 특유의 인상을 강화함 | 휴대폰에서는 화면과 버튼이 지나치게 작아질 수 있음 |
| 컬러 화면과 회전형 몸체 | 컬러 메뉴와 여러 자세를 표현하기 좋음 | 오래된 기기의 향수보다 비교적 현대적인 학습기 인상이 강할 수 있음 |

위 외형 비교는 초기 조사 제안이다. 최신 요구에 따라 먼저 기준 기종 하나를 선정하고, 그 기종의 기능과 외형을 충실하게 재현하는 순서를 제안한다. 초기 실험의 축소된 기능을 완성된 재현으로 취급하지 않는다.

컬러·회전형의 공식 참고 자료로 SHARP Brain PW-S3는 360도 오픈 디자인과 5.5형 컬러 LCD를 소개한다. [공식 제품 개요](https://jp.sharp/edictionary/products/pws3/overview/)

CASIO EX-word XD-SX의 공식 기능 소개에는 사전·모드 키에 자주 사용하는 콘텐츠를 등록하는 방식이 설명되어 있다. 버튼이 단순 장식이 아니라 자주 쓰는 기능으로 바로 연결되는 점을 참고할 수 있다. [공식 기능 소개](https://www.casio.com/jp/exword/brand/function/sx/)

## 첫 시제품에서 확인할 경험 — 제안

1. 전원 키를 눌러 LCD 화면이 켜진다.
2. 사전 모드를 선택하고 화면상의 키로 짧은 검색어를 입력한다.
3. 방향키로 결과의 선택 표시를 옮긴다.
4. 확인 키로 뜻을 열고, 돌아가기 키로 기존 선택 위치에 돌아온다.

외형만 검토하는 임시 시안에는 소량의 예제 단어를 쓸 수 있지만, 첫 기능 검증 버전에는 실제 사전 검색을 포함해야 한다. 한국어·일본어·영어 입력, 결과 선택, 실제 뜻풀이, 출처 표시를 검증한다. 모든 언어쌍의 양방향 번역이나 모든 결과의 한국어 뜻풀이가 데이터 하나로 해결된다고 가정하지 않는다.

기존 사전과 신조어 데이터를 같은 검색에서 찾되 결과마다 출처와 성격을 표시하는 방식을 제안한다. 신조어에는 뜻, 직접 작성하거나 사용 권한을 확보한 예문, 사용 국가·맥락, 최근 확인일을 둔다. 즉시 자동 등재보다 근거 확인과 편집을 거치는 소규모 데이터로 시작하는 것이 제안이며, 초기 단어 수와 갱신 주기는 아직 확정하지 않았다.

첫 외형에는 본체 테두리, 화면의 안쪽 그림자, 실제로 작동하는 키, 선택 행의 반전 표시가 중요하다. 원래 기기의 버튼 소리는 사용자 요구다. 음원 확보 방식과 선택 기종의 실제 동작을 확인한다. 광고·계정·구독·개인 데이터 클라우드 동기화·AI 번역은 현재 범위에 없다. 사전 데이터 배포·갱신은 범위에 포함한다.

## 플랫폼 결정

- **iOS 네이티브 우선, Android 네이티브 후속**으로 결정했다. 처음에는 iPhone을 기준으로 제안한다.
- 세로 화면에서 펼친 본체 전체를 보여 주면 키가 작아진다. 실제 비율과 터치 편의를 함께 검증하고 화면 확대·입력 보조를 별도로 제공하는 방향을 제안한다.
- SwiftUI의 원근 회전 기능을 Context7의 Apple 문서로 확인했다. 2D 레이어 표현과 실제 3D 모델 중 선택은 기준 기종의 시각 검증 후 결정한다. 의존성 설치나 제품 코드 작성은 하지 않았다.
- 현재 Windows 작업 공간에서는 Xcode 시뮬레이터와 iPhone 검증을 수행하지 않았다. 실제 빌드·배포 검증에는 Mac의 Xcode 환경이 필요하다.

## 다음 결정

가장 먼저 완전히 재현할 기준 기종을 선정한다. 데이터 쪽에서는 사용자 언어별 기본 사전과 요청 시 제공할 한국어·영어 사전의 공급원을 선택하고, 기존 기기의 수록 사전·학습 콘텐츠 재현 가능 여부를 별도로 확인한다. 각 데이터의 언어 방향과 수록 범위를 확인한 뒤 실제 제작할 설계와 구현 계획을 작성한다.

이 문서는 조사 요약과 제안이며 제품 코드, 완성된 시제품, 승인된 구현 계획을 대신하지 않는다.
